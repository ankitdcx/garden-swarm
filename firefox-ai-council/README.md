# AI Council Firefox v0.1
Open and log into supported AI web chats in separate tabs: ChatGPT, Gemini, Claude, Grok, DeepSeek. The extension popup can ASK ALL, CROSS-CHECK, FINAL, and STOP.

This is DOM automation. Site UI changes can break an individual adapter; selectors are isolated in content.js.

For Firefox Android, extension installation support varies by Firefox channel/version. If unsigned local extensions are blocked, use Firefox desktop for initial testing or package/sign the extension through Mozilla's extension distribution path.
