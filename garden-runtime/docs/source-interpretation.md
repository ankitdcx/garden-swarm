## Implementable control semantics

Canonical `K-INT-010`, `HSA-007`, `INT-001` and `AGT-016` separate capability, intention and authority. Identity authentication identifies a subject; it does not grant permission. Delegations need authenticated principals, scope containment, expiry, revocation and point-of-use checks. `AGT-005/007` reject self-delegation and cycles. `AGT-001` specifies depth five for the current profile plus principal-wide breadth/rate/cumulative limits; five is not presented as a universal Garden constant.

`RESULT-ALG-002`, `K-INT-002/006/012` require explicit UNKNOWN, conflict, stale and exhausted states. Unknown independence counts conservatively as dependent. A repeated model, prompt or evidence source is not independent corroboration. `VER-003`, `DEPOCH-010` and `SEC-LEARN-003` keep the smallest checker outside ordinary evolution authority and prohibit sole self-certification of its replacement.

The existing authority implementations intersect all principal/member/swarm or causally controlling artifact scopes. This is a useful reference mechanism. Existing `prototype/actiongate.py` demonstrates deny/escalate behavior but accepts caller-supplied booleans such as `independent_review`; a deployed runtime must authenticate verifier attestations and hold the policy/check requirements outside the proposer process. Its permissive default `context_trust=trusted` is unsuitable as an untrusted request admission default.

`FUNC-003/007`, `ACT-003/008/009/011` bind effect contracts, explicit approval obligations, resources, invalidators and cached-assurance freshness. Missing required approval is not approval. `EXE-005` supplies duplicate action idempotency. Receipts report decisions and effects; a hash or signature establishes identity/integrity within a key assumption and does not establish semantic correctness. A local hash chain without an independently preserved checkpoint cannot detect complete history deletion by the host administrator.

Human-Effect Closure and REP add candidate detail to already canonical rights/authority boundaries. The current mission explicitly requests their implementation. Unknown materiality remains non-PASS; proposer assertion cannot declare its own action harmless. Representation diversity records materially different views and losses, not merely distinct serializations. Required QSE exploration yields evidence and findings; it never creates an execution grant. Strategic truthfulness can be checked over explicit decision records and omission attestations for a declared scope; this runtime cannot mechanically establish completeness of arbitrary free-form statements.

The proposed Garden request DSL is a versioned implementation IR aligned with typed authority/evidence/effect contracts. It does not replace GSL v45.1 or claim complete GSL grammar/compiler conformance. Translation must preserve source status and may not raise authority or certainty (`LANG-007`).

## Unresolved admission limits

1. Required substantive independence is multidimensional. Separate processes or different role labels do not prove model, evidence, representation, administration or trust-root independence. Shared lineage must remain visible; unavailable required independence blocks that level of admission.
2. Canonical `HSA-016` requires environment/version-bound certification for imported model admission. No such certification is established here. An isolated open-model cognition adapter produces untrusted proposals under an experimental test envelope; it is not fully admitted or certified Garden AI.
3. The finite policy/effect classifier only covers registered harmless tools. Missing effect classes, unknown affected persons, arbitrary program effects and general strategic deception remain unresolved and cannot acquire permission from a self-declared low-risk label.
4. Container/process separation depends on the host kernel, administrator, credentials, filesystem permissions, network policy and mount configuration. A host owner capable of rewriting the gate is outside the implemented model-process threat boundary; hardware-root independence is not established.
5. No canonical exact named QSE Rev 2 package or complete Strategic Truthfulness successor contract was located in the inspected current paths. Current mission requirements supply the finite implementation contract, while canonical status remains unresolved.
6. Full newer successor packages are hash-bound externally and not fully materialized by the selected repository files. Current candidate projections/deltas are used only within their declared scope.
7. Android code appears only in retired archive branches. The recovered relay transports model review packets via Android Share intents; it is not an active Garden runtime console or proof of APK availability. A responsive console/API can be implemented independently; Android packaging remains a separate implementation step.

Every unknown above remains an explicit limit. The completion statement may describe only the declared source/test/search surface and budget, never global safety or exhaustive absence of bypasses.
