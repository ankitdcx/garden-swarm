DIRECT LOCAL RECONCILIATION CANDIDATES

1. EDUCATION CREDENTIAL PROOF PROFILE
IssueCredential permits a selected approved privacy-proof method, including non-ZKP profiles. VerifyCredential locally still appears ZKP-only.
Candidate repair: credential issuance SHALL bind the exact CredentialProofProfile/method/version used. Verification dispatches to that bound approved verifier and returns VERIFIED / UNSUPPORTED_PROFILE / STALE / REVOKED / INVALID / UNKNOWN as appropriate. A non-ZKP approved credential must not be rejected solely because one legacy verifier assumed ZKP; unsupported verifier capability must not be reported as credential invalidity.

2. EVOLUTION U20 STALE FIELD
EvolutionState retains an `emergency_proof_override_gate` / `MultiSigEmergencyOverrideProtocol` style field historically tagged U20, while current U20 semantics are Automated POG Proof Discharge Gates and Garden separately forbids proof bypass.
Candidate repair: deprecate the stale field as a historical alias only where exact migration requires it; map no current execution semantics to 'proof override'. Current proof discharge remains owner-qualified, non-bypassable and evidence/proof bound. Old serialized state is migrated explicitly; absence of new proof is not replaced by multisig override.

3. RUNTIME / EXECUTION SUMMARY NORMALIZATION
Older local summaries such as timeout->abort and 'all-or-nothing transactions' are broader than later current external-effect semantics. P021 already retains PARTIAL_EFFECT, OUTCOME_UNKNOWN, irreversible residual, durable effect identity and reconciliation.
Candidate repair: mark short lifecycles/summaries as non-exhaustive projections and bind them to the authoritative result/effect contract. Scheduler cancellation is not a promise of physical halt or rollback.

4. OFFLINE RED / CRITICAL CONTINUITY
A RED/offline 'beacon-only/no execution' shorthand can conflict with independently authorized essential physical minimum-risk continuity.
Candidate repair: RED disables ordinary autonomy/execution. It does not revoke a separately current bounded critical-continuity authority lease/profile. Essential safe-control handoff remains independently authorized, tightly scoped and reconciled. Network loss itself creates no authority.

5. MOBILITY TIMING / ASSURANCE CONSTANTS
Local Mobility text contains fixed ASIL-D/50 ms style wording. Treat these as qualified reference-profile values unless the active domain owner explicitly selects them. Actual safety/timing requirements remain domain/ODD/profile bound and may be stricter or different.

6. LOCALE TRANSLATION RESULT TYPE
Locale.Translate returning plain String with unconditional meaning-preservation is too lossy for current GSL/Explanation semantics.
Candidate repair: translation returns or binds a typed TranslationResult/Explanation result preserving source/target locale, semantic status, ambiguity/loss/untranslatable state, provenance and applicable policy/rights constraints. Ambiguous/untranslatable does not become confident String. Governance cannot choose semantic truth merely because cultures conflict.

7. CARBON `Certify`
Carbon local `Certify` can be read as official external certification.
Candidate repair: distinguish internal EmissionCertificate/assessment/evidence package from authenticated external certification/issuer status. Footprint validity does not manufacture issuer authority.

8. MEDIA FIXED LIMITS
Older fixed display/flash/session reference numbers must yield to current user/device/domain-qualified profiles where the current source already provides such profiles. External standards terminology/thresholds require source/version verification before being called certified.

9. SPACE SNAPSHOT / RECOVERY
SEU snapshot rollback restores digital state only under validated recovery state. It cannot erase irreversible physical residuals. Reuse existing Transition/Execution/continuity semantics rather than a new recovery engine.

10. NATIVE / HARDWARE / SOFTWARE SIGNATURE BOUNDARY
Signed bytecode/firmware/kernel/driver identifies/authenticates an artifact but does not itself prove safety, qualification or authority. Existing attestation/qualification/current boot/calibration gates remain separate.
