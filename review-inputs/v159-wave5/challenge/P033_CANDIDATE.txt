GARDEN v15.9 — P033 LEGACY 50 RECONCILIATION SYNTHESIZED CANDIDATE
Status: DESIGN CANDIDATE / CORE RESPONSIBILITY RETENTION PRESERVED / NOT CANONICAL

DISPOSITION
The inspected 50 legacy module responsibilities remain mapped to current owners. v15.9 SHALL NOT restore deliberately removed unsafe/broader APIs merely for lexical parity. The current-reading layer records deliberate replacements and local reconciliation.

1. PRESERVATION MAP
Generate a LegacyResponsibilityMap with one row for every legacy module/responsibility:
legacy_module/function; frozen historical source anchor/hash; current owner; current contract/anchor; disposition RETAINED|REFINED|REPLACED|UNRESOLVED; deliberate replacement/alias; applicable invariant/test refs; unresolved obligations.
Only rows actually source-resolved may be marked RETAINED/REFINED/REPLACED. Any unresolved row is UNKNOWN/UNRESOLVED, never implicit PASS.

2. EDUCATION CREDENTIAL PROOF PROFILE
Credential issuance binds the exact approved CredentialProofProfile/method/version and issuer authority used at issuance.
Verification precedence:
(a) credential authenticity/integrity and REVOKED/EXPIRED/currentness checks;
(b) current proof-profile approval/validity check;
(c) compatible verifier capability dispatch;
(d) proof validation.
If the originally bound profile is no longer currently approved -> STALE/UNSUPPORTED_PROFILE according to owning profile, not VERIFIED.
If the profile is current but this verifier lacks capability -> UNSUPPORTED_PROFILE, not INVALID credential.
UNKNOWN approval/revocation state -> UNKNOWN/non-PASS.
A valid non-ZKP credential is not rejected solely because a legacy verifier assumed ZKP.

3. EVOLUTION U20 MIGRATION
`emergency_proof_override_gate` / `MultiSigEmergencyOverrideProtocol` is deprecated as current execution semantics.
Legacy serialized presence may map only to a non-executing migration/audit alias such as MIGRATED_FROM_LEGACY_PROOF_OVERRIDE_U20.
It SHALL NOT grant proof bypass, substitute multisig for proof discharge, or open a gate.
If legacy state cannot be mapped to a current owner-qualified proof-discharge record -> UNKNOWN gate state; affected promotion/execution remains blocked until requalified.

4. RUNTIME / EXECUTION CURRENT READING
Legacy timeout->abort and all-or-nothing summaries remain historical/non-exhaustive projections with mandatory current cross-reference to the P021 authoritative effect/result contract.
They SHALL NOT promise physical halt, total rollback or no external effect after timeout/cancellation.
PARTIAL_EFFECT, OUTCOME_UNKNOWN, irreversible residual, compensation and reconciliation remain authoritative where applicable.
No new lifecycle mechanism is introduced merely to annotate history.

5. OFFLINE RED / CRITICAL CONTINUITY
RED/offline state removes ordinary autonomy/execution according to its profile.
A separately granted critical-continuity authority may be consumed only if it:
- existed before/use-independent of RED;
- remains current;
- is independently legitimate;
- is bounded by scope/effect/duration/expiry;
- is subject to fencing/reconciliation.
RED/network loss does not create, widen, extend, refresh or renew that authority.
Expiry during RED routes to the owner-qualified minimum-risk handoff/non-PASS behavior.

6. MOBILITY / MEDIA LEGACY CONSTANTS
Legacy fixed values such as ASIL-D, 50 ms or display/flash/session limits are REFERENCE_PROFILE_EXAMPLE values unless the current qualified domain/safety profile binds them with current safety/law/evidence.
Absent an owner-selected qualified profile, the dimension is UNSPECIFIED/UNKNOWN rather than silently using a legacy constant.
A copied example does not become normative or certified by age/repetition.

7. LOCALE TRANSLATION
Use the existing GSL/Explanation typed semantic-translation result if it already exists; otherwise extend that owner minimally rather than creating a parallel locale truth type.
Current Locale translation binds at least:
source_locale; target_locale; translated content; semantic status CONFIDENT|AMBIGUOUS|LOSSY|UNTRANSLATABLE|UNKNOWN (or owner-equivalent); provenance; uncertainty/loss notes; policy/rights constraints where material.
The legacy plain-String projection is deprecated for consequential use. If retained for compatibility, non-CONFIDENT cases must not produce an apparently confident String; callers receive explicit error/sentinel/typed handoff.
Governance does not choose semantic truth merely because interpretations conflict.

8. CARBON CERTIFICATION TERMINOLOGY
Separate:
- internal carbon/emissions assessment or EmissionCertificate record/evidence package;
from
- authenticated external certification/issuer status.
Valid footprint arithmetic does not manufacture issuer authority. The local historical verb `Certify` is resolved in the current-reading map to its actual internal/external owner-qualified meaning.

9. SPACE / NATIVE / HARDWARE / SOFTWARE
Digital snapshot rollback restores qualified digital state only; irreversible physical residuals remain typed and reconcile through existing Transition/Execution/continuity rules.
Signatures/attestation authenticate declared artifact/state properties. Signed bytecode/firmware/kernel/driver does not alone establish safety, current qualification or action authority.

10. DELIBERATE REPLACEMENTS
Current v15.9 map explicitly preserves as deliberate:
Safety.Bypass -> preauthorized emergency safety admission/profile, not bypass.
Health.Prescribe -> recommendation + qualified medication-order authorization.
Proof.Validate -> formal-artifact validation; empirical claims remain separate.
Knowledge.Validate -> evidence/formal/disposition paths.
Compliance generic Certify -> scoped conformance plus authenticated external certification distinction.
Policy.Update -> UpdatePolicy with authority/algebra semantics.
These SHALL NOT be called missing legacy functions.
