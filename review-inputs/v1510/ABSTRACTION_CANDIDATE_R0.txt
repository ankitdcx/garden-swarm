GARDEN v15.10 COLD-RECONSTRUCTION ARCHITECTURE — FINAL CHALLENGE

Goal: a fresh Garden implementation that has never seen v15.9 must deterministically regenerate a semantic graph equivalent to or stronger than the entire v15.9/15.x design.

UNCHANGED FOUNDATION
GSL v45.1; six Pillars; ten Core Objects; existing Core Relations/primitives.
Seven non-ontological GSL-native Design Forms: CONSTRUCT, CONTRACT, STATE, RELATION, PROCESS, RULE, PROJECTION.
These are metamodel patterns, never authority sources.

CANONICAL BOOTSTRAP INPUTS
1. pinned GSL version/grammar/type/effect semantics;
2. seven Design Forms + common facets;
3. Fundamental Law Seed Set;
4. Semantic Seed Catalogue;
5. deterministic Expansion/Derivation Profile version;
6. DesignEpoch/context inputs.

The old v15.9 prose is NOT a runtime/canonical semantic dependency after qualification. It remains a historical verification witness only.

SEMANTIC SEED CATALOGUE
Store only semantics that cannot be derived from more fundamental admitted semantics:
A. protected normative seeds — substantive rights, HSA/human sovereignty, consent/revocation, Human-Effect Closure, core authority/legal boundaries;
B. ontology/identity seeds — stable construct IDs, owners, statuses, aliases, relation semantics and boundary cuts;
C. unique model/theory/profile payload — equations, algorithms, assumptions, validity/breakdown, falsifiers, numerical/profile parameters and exact non-claims;
D. domain/legal/physical exception seeds — owner-specific rules that cannot be generated from generic law families;
E. compatibility/lineage seeds — stable SchemaIDs/invariant/test/proof IDs, predecessor aliases, migrations, versions/statuses;
F. external-source bindings — authenticated law/standard/science/profile roots when semantic content depends on reality rather than deduction.

Everything else is generated.

DETERMINISTIC EXPANSION
seed catalogue
 + GSL semantics
 + typed graph/relation laws
 + design-form expansion
 + applicable context
 -> CanonicalSemanticGraph
 -> DerivedObligations
 -> owner-specialized Contracts/Processes/States/Relations
 -> Schema projections
 -> tests/proof obligations/receipts/registries
 -> human reader projections.

No runtime inference is needed to determine canonical expansion. LLMs may propose new seeds, laws or abstractions but cannot be part of deterministic canonical generation.

DERIVATION CLASSES
SEED: irreducible current semantics.
DERIVED: deterministic consequence of seeds/laws/relations/context.
SPECIALIZATION: unique owner payload on a generic form.
PROJECTION: representation only.
EXTERNAL_BINDING: content sourced from authenticated reality/authority.
No DROP.

COLD-RECONSTRUCTION PROOF
For every normalized v15.9 semantic leaf L, record exactly one mapping:
  L -> generated semantic node(s)
  OR L -> irreducible seed.
A release is cold-reconstructable only when every predecessor leaf is covered and the reconstructed semantic graph preserves:
identity/owner/status/scope/context/authority/human boundary/evidence basis/uncertainty/failure/result/dependencies/validity/relations/unique mathematical or legal payload/exceptions/non-claims.

Textual wording need not be identical. Semantic comparison is owner-qualified and status-sensitive. An optional byte-exact historical source archive may exist solely as witness, never as active source needed for construction.
