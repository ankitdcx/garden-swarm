CURRENT v15.8 BASELINE EXTRACT
Garden Core is the minimum technical machinery required by every Garden instance.
GSL v45.1 uses six Pillars, ten Core Objects, 24 Core Relations and current universal semantic primitives.
Provenance/state core includes DesignManifest, DesignEpoch, DesignBinding, KnowledgeSnapshot, EnvironmentCommitment, CanonicalStateRecord, source-span provenance, immutable historical lineage, content-addressed registries.
Proof, test, evidence, attestation, assurance and applicability remain distinct typed results. Failure, timeout, resource limits, staleness, inconclusive and unknown states are preserved rather than collapsed into Bool.
Bool is reserved for total deterministic predicates whose valid input space has a semantically complete true/false interpretation.
Canonical IDs are owner-qualified and ambiguous short aliases HALT with AMBIGUOUS_IDENTIFIER.

V15.8-CARRIED GSL GAP CANDIDATES

- QueryStmt resolves QueryResultBinding; query without `into` requires a declared FunctionContract sink or QUERY_RESULT_UNCONSUMED; no implicit Knowledge mutation/Evidence creation.
- `causes` remains one Core Relation; operational edge carries CausalRelationLevelBinding(C0..C4); lower-level consumption as stronger returns CAUSAL_LEVEL_UNDERFLOW.
- R0 is SanityGate, not an Engine.Reason mode; PASS|FAIL|UNKNOWN; must not recursively invoke Reason.
- ProvenanceClassManifest distinguishes REDACTED/PROTECTED, PROVENANCE_GAP and NOT_APPLICABLE without leaking protected payload.
- AuthorityDecl and EffectDecl are FOUNDATIONAL_CONTRACT catalogue entries; declarations do not manufacture authority.
