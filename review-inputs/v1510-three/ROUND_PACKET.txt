R1 PATCHES NOW APPLIED

A. CLOSED RECONSTRUCTION BOUNDARY
- Technical now pins six GSL Pillars, ten Core Objects, 24 Core Relations, 14 primitive/control families, effect dimensions and key relation laws.
- Canonical design expansion performs no network, wall-clock, LLM or ambient-environment read.
- The canonical build context is an immutable typed snapshot with its own hash.
- Runtime context/observations are explicit inputs to runtime evaluation, not hidden design-build inputs.

B. SEVEN FORMS CLAIM NARROWED
- CONSTRUCT/CONTRACT/STATE/RELATION/PROCESS/RULE/PROJECTION are overlapping metamodel patterns, NOT claimed minimal/nonredundant ontology.
- GSL Core Objects/Relations remain ontology.
- Orthogonal semantic-role qualifiers are explicit: RIGHT, obligation/proof/test, non-claim/prohibition-of-inference, eligibility/authority, model-equation, profile assumption, observation/measurement, etc.
- No eighth Form is added merely for Query/Event/NonClaim; these are semantic roles or macros over existing Forms.
- Macro name is an explicit discriminator even when two macros share the same Form set.
- Added reusable macros: Query, EventSubscription, ContinuousWorker, DynamicalSystemProfile, AuthorityGatedContract, RecoveryEnvelope.

C. STORAGE DAG != SEMANTIC GRAPH
- Catalogue record stream/content addressing is acyclic storage.
- Semantic relations may be cyclic through stable symbolic identity/reference edges.
- Catalogue now carries explicit STRUCTURAL_EDGE records:
  * DOCUMENT_CONTAINS
  * SOURCE_NEXT
  * IDENTIFIER_REFERENCE
- Current structural edge count: 9,119.
- Semantic envelopes bind payload to canonical ID, definition owner, status, source span/root, macro/forms/facets/laws/roles and predecessor family metadata.

D. FINITE STRATIFIED EXPANSION
The old generic "monotone least fixed point" claim is removed.
Canonical expansion is:
  STRATUM 0: validate and materialize immutable laws/seeds/residuals/index/structural/formula records.
  STRATUM 1: generate only finite seed-local facet bindings, check obligations and projections.
  STRATUM 2: canonical ordering + hash.
Derived nodes are never fed back as rule inputs. A computed finite node bound is checked.
Current build:
  graph nodes = 34,992
  expansion_mode = FINITE_STRATIFIED_SEED_LOCAL
  no ambient reads
  no LLM
  completion must be COMPLETE; budget exhaustion may never produce canonical PASS.

E. HISTORY != CURRENT APPLICABILITY
- Immutable historical assertion/derivation is never deleted merely because current applicability changes.
- Technical defines separate applicability outcomes including APPLICABLE, NOT_APPLICABLE, CONDITIONAL, UNKNOWN, STALE, CONFLICT, BLOCKED, REVOKED, INVALID.
- Revocation/expiry/dependency invalidation change current effective status, not historical bytes.
- Design build itself performs no runtime applicability filtering.

F. CONTEXT/TIME
- Canonical build context is content-addressed and fixed.
- No ambient clock.
- Runtime implementations must keep validity/event/record time explicit where applicable.
- Context widening remains forbidden unless an explicit authorized rule admits it.

G. DEFINITION OWNER != ACTION AUTHORITY
- Graph now uses definition_owner semantics.
- A Catalogue owner string never supplies authority to act, approve empirical equivalence, waive another person's rights, or self-certify a protected boundary.
- Derived/index/projection nodes explicitly create no action/epistemic authority.

H. EPISTEMIC/CONFLICT FOUNDATION
Technical pins the v15.9 epistemic dispositions and UNKNOWN subtypes and retains the rule that UNKNOWN/CONFLICT/STALE/NOT_APPLICABLE are distinct.
Absence of a fact is not FALSE; duplicate/correlated support cannot become independent confirmation without a declared model.
Formal proof, empirical evidence, validation and certification remain non-substitutable.

I. PRIVACY/RETENTION BOUNDARY
- Catalogue contains public/static design semantics, not personal runtime evidence/data.
- Instance data/evidence remains governed by Privacy/Law/DataLifecycle semantics in the Catalogue/runtime.
- Hashing is never treated as anonymization.
