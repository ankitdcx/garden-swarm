3. PREDECESSOR PRECEDENCE

There is NO DROP operation.

4. PURE FINITE EXPANSION — NO OPEN FIXED POINT
Canonical build has 3 strata:
S0 = validate/materialize immutable Catalogue records.
S1 = simultaneous seed-local pure Emit(seed, admitted-law-id-set). Every Emit:
- reads only immutable S0 seed metadata;
- is total over finite fields;
- emits at most |facets| + |laws| + 1 nodes;
- cannot inspect another S1 output;
- cannot run theorem search/proof search;
- cannot create action/epistemic authority;
- incompatible identity collision = deterministic FAIL.
S2 = ordering/serialization/hash only; it cannot affect applicability or create obligations.
Current build:

This deliberately does NOT perform transitive normative reasoning during canonical design construction. Transitive/recursive analysis is a separate bounded runtime/assurance process under existing Process/Dependency/Reason/Proof semantics.

7. REFERENCES ARE SNAPSHOT-BOUND
Every identity index is inside the pinned Catalogue root.
No canonical "latest" lookup.
Ambiguous duplicate identity = build error.
Missing reference resolves to typed UNRESOLVED_REFERENCE and cannot be treated as resolved.
Reference resolution does not create authority or truth.

8. HISTORY AND CURRENT APPLICABILITY ARE SEPARATE
Historical seed/source bytes are immutable.
Current runtime applicability is computed, not stored by mutating them.
ApplicabilityVector/v1 is a product, not a flattened enum:
- logical: SATISFIED | VIOLATED | INDETERMINATE | NOT_EVALUATED
- epistemic: PROVEN | VERIFIED | SUPPORTED | UNVERIFIED | CONTRADICTED | UNKNOWN | STALE
- authority: AUTHORIZED | UNAUTHORIZED | REVOKED | EXPIRED | UNKNOWN
- scope: IN_SCOPE | OUT_OF_SCOPE | CONDITIONAL | UNKNOWN
- dependency: VALID | STALE | INVALID | CONFLICT | UNKNOWN
- resource: AVAILABLE | DEGRADED | RESOURCE_UNKNOWN
No axis substitutes for another. Owner-qualified point-of-use contracts consume this product; Technical provides no universal scalar effective-status function.

9. DEFINITION OWNER != ACTION AUTHORITY
Catalogue leaf owner is definition ownership only.
Seed/index/projection existence grants no action authority.
Generated nodes carry authority_effect=NONE.
Protected owners cannot self-certify their own protected boundary merely because they own a definition; ordinary Garden HSA/Proof/Authority rules remain controlling.

10. EPISTEMIC SEPARATION
Observation/Evidence/Claim/Knowledge/Prediction/Proof/Validation/Certification remain non-substitutable.
UNKNOWN/STALE/CONFLICT/NOT_APPLICABLE remain distinct.
Generated nodes carry epistemic_effect=NONE.
Agreement/count/hash does not create evidence/truth.

11. SAME-LEAVES-CHANGED-MEANING DEFENSE
R3 no longer claims hashes infer semantics.
Instead:
- exact whole predecessor source bytes are Catalogue seeds;
- enclosing section/anchor units remain active;
- source ordering/containment is explicit;
- formulas point to enclosing units;
- structured generic output is subordinate to predecessor source unless accepted equivalence/strengthening exists.
Thus a detached exception or broadened formula cannot erase the original qualified semantics: the original section remains controlling and the new interpretation cannot supersede it without an explicit admitted delta.

12. TEST INDEPENDENCE
Predecessor test semantics remain source/Catalogue seeds.
Technical may generate harness/check-surface projections, never expected truth or PASS from itself.
Generated projections do not certify the implementation.

14. PRIVACY

15. TECHNICAL/CATALOGUE OWNERSHIP
Technical = generic mechanics only.

Generic Technical validation may reject malformed Catalogue structure but cannot decide that a specific Catalogue right/law is false, waived, unnecessary or semantically overridden.
