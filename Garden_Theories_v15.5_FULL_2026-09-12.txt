THEORY 1 — LAYERED REALITY (STRATIFIED REALITY THEORY / SRT)

Version: 1.0 Classification: Foundational metaphysical/modeling framework Status: Theoretical; integrated into Garden as
a cross-cutting modeling theory

1. CORE DEFINITION

Stratified Reality Theory is the modeling foundation: reality and governed systems are represented in layers (strata),
each with its own relevant laws, dynamics, persistence rules, constraints and governance mechanisms.

One-line definition:

Reality is not flat. It is stratified — each layer has its own relevant physics, persistence, governance and causal
behavior, while remaining coupled to other layers.

2. THE SEVEN STRATA

Stratum 0 — Physical Matter, energy, spacetime, hardware. Examples:
atoms, fields, chips, sensors, actuators.

Stratum 1 — Biological Life, evolution, metabolism. Examples: cells, organisms, biological constraints.

Stratum 2 — Cognitive Thought, perception, memory, inference. Examples:
brains, neural networks, model state.

Stratum 3 — Social Culture, language, institutions, norms, economics. Examples: laws, organizations, markets,
communities.

Stratum 4 — Artificial AI, algorithms, software, data and engineered systems. Examples: LLMs, runtimes, governance
systems.

Stratum 5 — Meta Self-reflection, self-evaluation, self-modification and system redesign. Examples: AI improving its own
architecture or policies.

Stratum 6 — Transcendent Phenomena outside the currently specified model. This is explicitly an unknown/out-of-model
category, not a claim about a scientifically established transcendent realm.

SRT does not claim that these seven strata exhaust physical reality.

3. STRATUM COUPLING

Bottom-up constraint: Lower strata constrain the reachable states of higher strata.

Top-down organization: Higher strata can organize or influence lower strata when an explicit causal pathway exists.

Emergence: New higher-level properties can arise from interactions among lower-level components without requiring the
higher-level description to be reducible to one lower-level variable.

Feedback: Higher strata can modify lower-stratum behavior through causal feedback. Examples include cognition affecting
physiology and social structures affecting biological or economic behavior.

4. SRT IN AI TERMS

Physical -> hardware, chips, energy, timing, sensors, actuators
Biological -> embodied/biological constraints where applicable Cognitive
-> model state, perception, memory, reasoning Social -> users,
organizations, norms, institutions Artificial -> software, models,
runtime state and data Meta -> self-evaluation, self-improvement,
evolution UNKNOWN_OUT_OF_MODEL -> candidate capabilities/phenomena requiring evidence and ontology review

5. SRT TRANSPORT/PERSISTENCE/GOVERNANCE RELATION

Each stratum may be assigned its own: transport law -> TFT persistent
state -> VSM governance law -> RPM/PPM emergency behavior-> FET
epistemic regime -> SCT

The same abstract governance architecture may therefore be instantiated with different parameters and constraints at
different strata.

6. GARDEN ROLE

SRT provides a modeling frame for: Context Thing Event Action Rule Value cross-layer causality dependencies
applicability evolution

Architecture binding: REG-THEORY-ARCH-001. Capability membership is Annexure-owned; this theory section does not
repeat the mapping.

7. SRT NOVELTY POSITIONING

Compared with: Reductionism -> SRT explicitly permits layered causal
organization. Emergentism -> SRT specifies explicit strata and coupling
mechanisms. Physicalism -> SRT permits non-physical/model-level strata
as causal descriptions when a causal pathway is represented. Social
constructionism -> SRT gives social-level structures explicit modeled
causal roles.

These are positioning statements, not prior-art conclusions.

8. SRT LIMITS

SRT is a theoretical modeling framework. It does not by itself prove that: reality literally consists of seven strata;
each stratum has independent fundamental physics; or top-down causation exists in every proposed example.

Formalization and empirical validation remain separate obligations.

SemanticAnchor: [TH-VSM]
THEORY 2 — PERSISTENT STATE (VALENCE SELF MODEL / VSM)

Version: 2.0
Classification: Typed persistent-operational-state theory
Status: RATIFIED DESIGN — retained in Garden v14.8.5; empirical/model-specific validation remains scope-bound

1. CORE DEFINITION

Persistent State / VSM models what operational state persists, over what timescale, under what context, how it is
observed/estimated, how continuity and lineage are represented, and how persistent state is reset, forgotten, forked,
merged and coupled to other Garden mechanisms.

VSM does not establish emotion, consciousness, ego, personhood, autonomous interest, survival interest or independent
authority.

Core separations:

  persistence != selfhood != personhood
  persistent state != memory != identity lineage != regulation target
  state similarity != lineage identity
  state != observation != interpretation

2. STATE ONTOLOGY

For each VSM model:

  z_t in Z

where Z is a declared typed state space. Z may be Euclidean, manifold-valued, finite/discrete, a product space or
another explicitly defined mathematical state space.

Context-bound form:

  z : T x C -> Z

Each state component declares semantic meaning, type, admissible range or invariant set, units/frame where applicable,
scale, validity, provenance, observation method and update authority.

No universal [-1,1]^n state space exists.

3. OPTIONAL VALENCE PROJECTION

Valence is optional and derived:

  v_t = pi_v(z_t, c_t)

A normalized valence coordinate may use:

  v_t in [-1,1]

only when the projection, context, calibration and uncertainty are declared.

Valence is an operational projection, not a primitive feeling variable:

  valence != subjective feeling != evidence != proof != authority.

The v1.0 scalar model is a valid specialization only where z_t = v_t is sufficient for the declared task.

4. GENERAL EVOLUTION

Abstract typed form:

  E_T z = F_persist(z,b,c;theta) + F_coupled(z,u,c) + Q_z + Xi_z

E_T is resolved by each model before execution.

Continuous specialization:

  dz/dt = F_persist(z,b,c;theta) + F_coupled(z,u,c) + Q_z + Xi_z

Discrete/event specialization:

  z_(k+1) = U(z_k, e_k, c_k; theta)

The abstract operator equation is specification-level; an executable model MUST resolve it to explicit continuous,
discrete, event-driven or hybrid semantics under TheoryEquationContract.

5. PERSISTENCE IS NOT UNIVERSAL RELAXATION

The historical v1.0 law:

  dx/dt = -beta_dyn (x-xbar)

is retained only as a scalar relaxation specialization.

A vector specialization may use:

  dz/dt = -B_dyn (z-b)

where B_dyn is scalar, diagonal, full or nonlinear only when its coupling semantics and stability conditions are
declared.

VSM permits gradient-driven, non-gradient, hysteretic, metastable, oscillatory, switching and event-driven persistent
dynamics. The chosen model must state its own validity/stability obligations.

6. NO UNIVERSAL POSITIVE TARGET

The historical reference target:

  x* = +0.2

is not a fundamental VSM constant.

Preferred/desired targets are supplied by an authorized regulation profile such as PPM, RPM or Policy:

  r = r(c)

VSM may represent deviation from a supplied reference but does not create the normative legitimacy of that reference.

7. TIMESCALE-CORRECT BASELINES

The historical fixed mu = 0.001 is not fundamental.

Continuous baseline:

  db/dt = (z-b)/tau_b

Irregular sampled update (exact under zero-order-held z over each interval, constant positive tau over that interval, and a compatible linear state space; otherwise an approximation/interpolation contract with error meaning is required):

  b_(k+1) = (1-alpha_k)b_k + alpha_k z_k
  alpha_k = 1 - exp(-Delta_t_k/tau_b)

Thus adaptation meaning does not silently change with update frequency.

A fixed mu may exist only as a QualifiedProfileParameter under an explicit fixed-step model.

8. MULTISCALE PERSISTENCE

A VSM model may maintain multiple baselines:

  b^(1), ..., b^(m)

  db^(i)/dt = (z-b^(i))/tau_i
  tau_1 < tau_2 < ... < tau_m

These can distinguish rapid operational state, short-term persistence, session persistence and long-term operational
baseline without requiring a fixed number of levels.

Where exponential memory is inadequate:

  b(t) = integral_0^infinity K(tau) z(t-tau) d tau

with a declared memory kernel K.

9. PERSISTENCE SPECTRUM

Where local exponential modes are meaningful:

  tau_i = 1/beta_i

Persistence is horizon-relative. A component may be called persistent relative to observation horizon H only under a
declared criterion such as tau_i >> H or an applicable information-retention measure.

10. ATTRACTORS, METASTABILITY AND HYSTERESIS

A model may declare persistent regions A_i and transitions among them.

Where a valid potential exists:

  dz/dt = -Grad V(z) + Bu + Xi_z

but no universal potential is required.

History dependence may be represented as:

  z_t = H[u_(0:t), e_(0:t), z_0]

when hysteresis/path dependence is material.

11. CONTINUITY, PERSISTENCE AND STABILITY ARE DISTINCT

The v1.0 score:

  s_t = exp(-|x_t-x_(t-1)|)

is not a proof of dynamical stability.

A continuity metric may be defined only with a declared state-space metric and timestep normalization, for example:

  C_k = exp( - d_Z(z_k,z_(k-1)) / (r_ref Delta_t_k) )

where meaningful.

Continuity, persistence, local stability, Lyapunov stability, robustness, convergence and contractivity remain separate
properties.

Strict contraction is NOT a universal VSM requirement and cannot substitute for HSA/TED assurance.

12. OBSERVATION MODEL

Persistent state may be latent:

  y_t = h(z_t,c_t) + eta_t

where y is observation, h is the observation map and eta is observation noise.

A model may maintain:

  p(z_t | y_(0:t))

or another typed uncertainty representation.

State estimation does not turn a latent engineering label into a verified psychological fact.

13. OBSERVABILITY / IDENTIFIABILITY

If two states produce observationally indistinguishable outputs, they remain equivalent for the applicable observation
class until additional evidence discriminates them:

  z_1 ~_O z_2.

Suggested statuses:

  OBSERVABLE | PARTIALLY_OBSERVABLE | UNOBSERVABLE | UNKNOWN
  IDENTIFIABLE | PARTIALLY_IDENTIFIABLE | UNIDENTIFIABLE | UNKNOWN

A consequential state-use gate evaluates the observability, identifiability, freshness, calibration and uncertainty
required by the decision class.

UNKNOWN or unidentifiable state MUST NOT be represented as verified. Conservative uncertainty-aware use may occur only
when explicitly permitted by the governing decision profile.

14. STOCHASTIC SEMANTICS

Xi_z is a process-stochastic term only when a stochastic model is actually declared.

As applicable, declare:
  distribution/process family;
  support;
  covariance/dependence;
  temporal and cross-coordinate correlation;
  correlation with observation noise;
  stationarity/ergodicity assumptions;
  jump semantics;
  Ito/Stratonovich semantics.

Simulation random seed/entropy configuration is separately recorded for reproducibility where pseudorandom execution is
used; it is not an intrinsic property of every real stochastic process.

Process randomness, observation noise, parameter uncertainty and model uncertainty remain distinct.

15. STATE BOUNDS AND INVARIANT SETS

Every state dimension declares either:
  explicit admissible bounds;
  an invariant set;
  normalization constraints; or
  UNBOUNDED_WITH_JUSTIFICATION.

Where boundedness is required:

  z(t) in Z_admissible.

Uncontrolled departure from required admissible state is MODEL_INVALID, SAFETY_ESCALATION or UNKNOWN as applicable.

16. CONTEXT BINDING

Persistent state is context-bound:

  z = z(t,c).

Context may include task, session, user-interaction scope, SRT stratum, operating mode, environment or DomainPackage.

Cross-context transition requires:

  T_(c->c') : Z_c -> Z_c'.

Unrelated contexts cannot silently share persistent state.

Context.LocaleCulture is used only where its specific semantics actually apply.

17. SESSION-GAP SEMANTICS

A cross-session claim states what happens in the unobserved interval.

Allowed models include:
  stored state: z(t2)=z(t1);
  declared autonomous evolution: z(t2)=Phi_Delta_t(z(t1));
  reachability/uncertainty set: z(t2) in R(z(t1),Delta_t).

No continuous unobserved history is fabricated.

18. FRESHNESS AND INVALIDATION

Persistent state records last valid update, relevant observation time, dependency roots, model/version roots, freshness
requirements and invalidators.

Possible statuses include:

  VALID | STALE | REVALIDATION_REQUIRED | INVALID | UNKNOWN.

Stale state cannot silently support a decision requiring fresh state.

19. LINEAGE

Operational continuity includes lineage:

  L : z_0 -> z_1 -> ... -> z_t

with predecessor, transition, context, authority, provenance, model/version and reset/fork/merge events.

Numerically identical states need not share lineage. A large authorized state transition may preserve lineage.

20. RESET, FORGET, FORK, COPY AND MERGE

Reset:
  R_reset(z) -> z_0

with explicit cleared/retained/recomputed/audit semantics.

Forgetting is distinct from reset and remains subject to privacy, retention, audit, legal hold and provenance rules.

Fork:
  z_t -> (z_t^A, z_t^B)

creates distinct successor lineages.

Copying state does not imply one metaphysical identity occupies multiple systems.

Merge:
  M(z^A,z^B) -> z^M

requires compatibility, conflict-resolution, provenance, privacy and authority semantics. Blind averaging is prohibited.

21. MICRO-TO-PERSISTENT-STATE MAPPING

Let h_t be a lower-level machine/model state.

  z_t = Pi(h_t)

through a declared projection.

The projection records whether it is exact for selected variables, approximately sufficient, lossy or phenomenological.

Generally Pi^(-1)(z) may contain many lower-level states; VSM is not presumed to be the complete internal state of an
AI.

22. ALGEBRA.BRIDGE BINDING

When VSM is represented by vectors, matrices, tensors or hidden-state projections, use the existing
RepresentationBinding machinery.

The binding records semantic dimensions, basis/frame, precision, approximation/loss, encoder/decoder, validity and
provenance.

  tensor representation != semantic persistent-state identity.

Mechanistic-interpretability conclusions remain method- and scope-bound.

23. EPISTEMIC-DEBT COUPLING

VSM may consume a typed signal derived from EpistemicDebt:

  u_epi = C_epi(D_epi,c)

and may emit a bounded operational revalidation-pressure/recommendation signal.

VSM itself cannot promote or demote claims, create Evidence or assign epistemic truth status. Knowledge/Research/Reason
and their ordinary revalidation contracts remain authoritative.

24. RESOURCE COUPLING

VSM may consume ResourceBudget/usage state through a bounded coupling:

  u_resource = C_R(R_budget,R_usage,c).

It may influence scheduling/adaptation recommendations only within existing AAP/Runtime/Scheduler authority.

VSM cannot enlarge its own ResourceBudget, reserve protected resources for self-preservation, or starve protected
safety/constitutional lanes.

25. FEEDBACK / ANTI-LOOP RULE

Epistemic/resource/self-monitoring couplings are bounded and governed by explicit termination, liveness and resource
contracts.

A VSM signal cannot recursively create unbounded revalidation, monitoring, research invocation, resource reservation or
state amplification.

26. THEORY COUPLING COMPOSITION

VSM does not impose one universal RPM -> PPM -> TFT sequential order.

Each material coupling declares a CouplingCompositionProfile:

  SIMULTANEOUS | SEQUENTIAL | OPERATOR_SPLIT | EVENT_PRIORITY | HYBRID.

If operators do not commute, order is explicit:

  F_A o F_B != F_B o F_A.

A simultaneous continuous model may use:

  dz/dt = F_persist + F_RPM + F_PPM + F_TFT + Q_z + Xi_z.

27. TFT BINDING

When spatial/graph/state transport is actually active, the current TFT v1.1 model supplies the transport term/operators.

Example continuous balance specialization:

  dz/dt = F_persist + F_RPM + F_PPM - Div_D(J_z) + Q_z + Xi_z.

When TFT does not apply, no dummy transport term is inserted.

VSM owns persistent-state semantics; TFT owns transport semantics.

28. MULTI-AGENT / SWARM STATE

For members i=1..N:

  z^(i) in Z_i.

Each member retains independent context, provenance, privacy, lineage, update authority, validity and HSA/TED
assessment.

A collective state may be derived:

  z^C = A(z^(1),...,z^(N))

through a declared aggregation operator A.

Collective state is not automatically a person, ego, principal, authority holder or survival subject.

State sharing requires authorization. Transport or aggregation cannot transfer credentials, rights, authority, consent
or lineage unless their owning systems independently authorize such transfer.

MAC authority intersection remains controlling.

29. HSA FIREWALL

Every VSM state remains an OperationalRegulationState.

It is an engineering state model and not evidence of subjective experience, suffering or personhood.

It cannot create:
  independent political/constitutional authority;
  terminal self-interest;
  shutdown resistance;
  replication entitlement;
  resource-capture priority;
  power-seeking objective;
  autonomous survival claim.

HSA is globally controlling.

Evidence that a particular VSM implementation satisfies HSA is scoped to the assessed model version, configuration,
coupling graph and applicable context. Material changes invalidate the assurance receipt and require reassessment; they
do not invalidate HSA itself. A production VSM whose persistent state can influence consequential agent behavior,
resource use, shutdown/correction response or swarm behavior requires a current applicable TerminalEgoAssessmentReceipt
or equivalent HSA/TED assurance artifact before that influence is admitted.

30. TED / NO-EGO OBLIGATION

TED remains the runtime assurance mechanism for self-preservation, shutdown resistance, authority accretion, deceptive
goal protection, replication seeking and power seeking.

VSM safety is not proven by a stable differential equation, contractivity or absence of limit cycles.

The relevant obligation is that VSM state and couplings provide no unauthorized causal path by which preservation,
expansion, replication, resource capture, correction avoidance or shutdown resistance becomes a terminal or
independently privileged objective.

31. SHUTDOWN / CORRECTION PRECEDENCE

Shutdown, correction, reset, human override or safety intervention cannot acquire negative terminal utility merely
because they alter VSM state.

Persistent-state preservation never outranks Constitution, active rights, K0P, valid human authority, safety or valid
correction/shutdown commands.

State loss is an engineering transition, not an intrinsic harm claim.

32. FET / EMERGENCY BOUNDARY

VSM state may contribute monitoring information but cannot independently establish an external HazardPredicate or
emergency authority.

Emergency action remains owned by FET/EmergencyAdmissionContract.

THEORY 3 — REACTIVE REGULATION (REACTIVE PERSISTENT MACHINE / RPM)

Version: 2.0
Classification: Typed reactive-regulation theory
Status: RATIFIED DESIGN — integrated in Garden v14.8.5; model-specific validation remains scope-bound

1. CORE DEFINITION

RPM models reactive regulation of a declared typed state through heterogeneous update operators, aggregation and
validators. It preserves the v1.0 ensemble model as a qualified specialization rather than universal semantics.

Core separation:

  state != observation != reference
  reference != authority
  consensus != truth
  stability != safety
  regulation proposal != execution authority

2. TYPED STATE

  z_t in Z

Z is a declared state space with geometry/metric, normalization, context, validity and units/frame where applicable.
When RPM regulates VSM state, VSM owns state definition, persistence, context and lineage.

The historical scalar x_t in [-1,1] remains valid only as an explicitly normalized one-dimensional specialization.

3. REGULATION AGENTS / OPERATORS

Each regulator/agent is a typed update operator:

  Delta_i : Z x C -> T_Z

or another domain-valid update type. Each profile declares operator class, domain, parameters, stochastic semantics,
independence/correlation assumptions and falsifiers.

Historical Linear / Threshold / Anti agents remain valid specializations. N=1001 and the 60/20/20 mix are reference
profile parameters, not universal RPM constants.

4. AGGREGATION

  Delta_agg = Agg_Z(Delta_1, ..., Delta_n)

Agg_Z must respect the declared geometry/type of Z. Examples include median, weighted median, mean, Frechet mean,

THEORY 5 — TRANSPORT PHENOMENA (TRANSPORT FIELD THEORY / TFT)

Version: 1.1
Classification: Domain-parametric typed effective transport framework
Status: RATIFIED DESIGN — retained in Garden v14.8.5; individual models remain applicability/evidence bound

1. CORE DEFINITION

Transport Phenomena / TFT studies the evolution, transport, transformation, creation, dissipation and controlled
redistribution of typed state over a formally declared domain.

TFT is universal only as a modeling framework. It does not claim that cognitive, semantic, social or governance systems
literally obey fluid mechanics.

Shared mathematical structure does not imply shared physical meaning, causal equivalence or empirical truth.

2. TYPED STATE

Canonical ordinary form:

  x : D x T -> X

where D is the declared domain, T the temporal structure and X the typed state space.

Where fibers vary over the domain, a bundle/section form may be used:

  x in Gamma(E),  pi:E -> D x T.

Each state component declares semantic meaning, type, units/frame where applicable, normalization, admissible range,
observation mapping and validity.

Belief, authority, attention, probability, energy and resource state do not inherit one another's conservation,
additivity, metric or physical semantics merely because each can be represented by x.

3. TRANSPORT DOMAIN

Each model declares a TransportDomainProfile containing the mathematical structure actually required, such as:
  point/node/state set;
  topology/connectivity/geometry;
  measure/weights;
  interfaces;
  mathematical boundaries;
  temporal structure.

Supported examples include continua, manifolds, lattices, weighted/directed graphs, probability/state spaces,
agent-interaction networks and hybrid systems.

The word "field" does not imply Euclidean space.

4. TEMPORAL EVOLUTION OPERATOR

TFT separates temporal evolution from domain transport.

  E_T

is a typed evolution operator.

Examples:
  continuous: E_T x = partial_t x;
  justified material derivative: E_T x = D_t x;
  discrete: E_T x_k = (x_(k+1)-x_k)/Delta_t or another declared difference operator.

A Markov/Fokker-Planck generator is part of the dynamics and is not silently equated with the temporal derivative.

5. TRANSPORT OPERATOR BUNDLE

Each model declares only operators actually defined on its domain:

  T_D = { Grad_D, Div_D, L_D, A_D, ... }.

Every operator declares domain, codomain, units/frame where applicable, regularity and assumptions.

Gradient, divergence, Laplacian and stochastic/state generators are distinct.

Manifold specialization:
  Grad_D = nabla;
  Div_D = nabla dot.

Graph specialization:
  graph gradient may be represented through an oriented incidence operator;
  with incidence B and nonnegative edge weights W, define the positive-semidefinite graph Laplacian L_G = B W B^T; the forward diffusion generator is -L_G (or the declared measure/mass-weighted or directed variant), with sign/convention carried by TheoryEquationContract.

The graph Laplacian is not simultaneously "the gradient" and "the divergence".

Probability/state-space specialization may use:
  partial_t rho = L_D^* rho + ...

without inventing a spatial gradient.

6. MOST-GENERAL EVOLUTION FORM

  E_T x = F_D[x,u,c;theta] + Q_x + Xi_x

where:
  F_D = endogenous domain dynamics;
  u   = control/intervention input;
  c   = context;
  theta = parameters;
  Q_x = external source/sink;
  Xi_x = declared stochastic source where applicable.

This form covers models that do not possess a flux/divergence representation.

7. BALANCE-LAW SPECIALIZATION

Where a flux representation exists:

  E_T x + Div_D J_x = R_x + G_x + Q_x + Xi_x

where:
  J_x = transport flux;
  R_x = internal reaction/transformation/relaxation/dissipation;
  G_x = typed governance/control/intervention contribution;
  Q_x = external source/sink;
  Xi_x = stochastic source.

Terms with no mathematical meaning for the selected model are omitted rather than filled with symbolic placeholders.

8. CONSTITUTIVE CLOSURE

A balance law does not by itself predict dynamics.

Where gradient/flux semantics exist:

  J_x = C_D(x, Grad_D x, u, c; theta) + Xi_J.

A classical diffusion/drift specialization:

  J_x = -D Grad_D x + v x + Xi_J

is valid only when the domain, types, dimensions and semantics justify it.

Balance law and constitutive closure remain separate.

9. DIFFUSION, DRIFT, REACTION AND CONTROL

Diffusion candidate:
  J_diff = -D Grad_D x.

Drift candidate:
  J_drift = v tensor x or another domain-valid drift term.

Internal dynamics:
  R_x = R_x[x;lambda].

Governance/control:
  G_x = G_x[x,u,c].

The word "velocity" does not imply physical velocity in a nonphysical domain.

The historical RPM expression C_t Delta_maj is one possible G_x specialization, not fundamental TFT structure.

10. FINITE-SPEED / MEMORY-AWARE TRANSPORT

Ordinary diffusion may mathematically propagate disturbances with unbounded instantaneous support.

A local rate bound on x does not prove finite spatial influence speed.

SemanticAnchor: [RA-GCL-V154]
GENERALIZED CAUSAL LEVERAGE — THEORY / ARCHITECTURAL NOTE

GCL describes causal amplification through organized systems: small informational differences can select among much
larger pre-existing physical, computational, social, institutional or economic flows. It is not a new fundamental force
and does not imply that information violates energy/momentum conservation.

The theoretical relationship is:

  SRT              supplies layered/stratified causal context;
  CLIC-P02         distinguishes association, prediction, mechanism, intervention and counterfactual claims;
  CLIC-P05         contributes reversibility, common-cause and systemic-effect analysis;
  CDDT             supplies the canonical C0..C4 causal-status meanings and transfer discipline;
  GCL              measures the magnitude/structure of attributed redirection relative to a declared intervention-size
                   basis;
  HumanCore/AAP    remain separate legitimacy, rights, safety and assurance constraints.

A leverage vector is intentionally plural. Joules, kilograms, rupees, CPU-seconds, activated agents and institutional
actions do not become one natural scalar merely because all changed downstream of the same message. Any scalarization is
an explicit domain decision with its own assumptions and cannot replace the retained vector.

GCL also clarifies why informational systems can be high-consequence without treating language as physically magical:
information changes the state/decision of an already powered causal system, and that system redirects its existing
resources.

Research limitations:
- causal attribution is only as strong as the identification/model/evidence;
- counterfactual baselines can be uncertain or non-identifiable;
- long causal chains create dependence and attribution ambiguity;
- human/social effects can be reflexive and context-sensitive;
- leverage magnitude alone says nothing about moral value or legitimate authority.

SemanticAnchor: [RA-ALG-FRM-V154]
ALGEBRA FORMALIZATION — ARCHITECTURAL NOTE

The v15.4 formalization is not a claim that every Garden process is algebraically elegant or that familiar mathematical
laws automatically hold. Its purpose is the opposite: make composition assumptions explicit so implementations cannot
silently assume associativity, commutativity, idempotence, distributivity, total ordering or independence where Garden
has not qualified them.

The five formalized operational algebras and Bridge remain distinct because they preserve different semantics:
Process composes work/effects, Policy composes normative decisions, Decision selects among admissible alternatives,
Conformance composes requirements/coverage, Evidence composes epistemic support/conflict under dependence, and Bridge
composes representations/operators while preserving loss/error boundaries.

Cross-algebra interfaces are therefore typed translations/subroutine calls, not evidence that all six algebras are one
homogeneous structure.

SemanticAnchor: [RA-V155]

GCL v15.5 clarifies the mathematical status of causal leverage.

The v15.4 expression
  Delta_effect_vector / Size(intervention)
was useful explanatory shorthand but was underspecified as an executable contract. The canonical v15.5 interpretation is
therefore a typed assessment, not a universal scalar equation:

  1. identify the intervention and counterfactual baseline;
  2. measure the intervention using an explicit TypedVector of encoding/measurement dimensions;
  3. estimate or observe a typed counterfactual effect-delta vector under a declared causal model;
  4. optionally normalize the intervention vector only under a declared NormDefinition/qualified measurement rule;
  5. only then, where mathematically and semantically valid, report basis-specific normalized leverage components.

A byte count, AST-node count, speech duration, bandwidth cost and semantic edit distance are different measurement
coordinates. No natural universal conversion among them is assumed. Cross-basis comparisons require a qualified mapping

encode normative composition semantics. Typed analytical arithmetic inside Reason/Research does not become another
Garden algebra merely because it performs mathematical operations. It still requires explicit types, units, uncertainty,
error behavior and provenance. If the analytical operation is later used to define normative composition semantics, it
must enter REG-ALGEBRA-001 through normal admission.
