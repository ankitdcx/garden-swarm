Runtime admission keeps Garden semantic admission separate from external host/provider enforcement. A host may block a
Garden-allowed effect, but host blocking cannot make an unauthorized effect allowed and host requirements cannot erase a
Garden rejection.

A consequential authority claim uses a typed AuthorityValidationReceipt bound to the exact content-addressed claim,
parent/delegator, active policy epoch, jurisdiction/context, authenticated identity, validity/revocation, evidence and
verifier identity/control lineage. Changing the claim or required context invalidates reuse.

A persistent goal uses a GoalLease bound to the active DesignEpoch/policy epoch, delegator, current authority-claim
digests, dependency digest/freshness, resource bounds, termination condition, invalidators and evidence. A separate
GoalValidationReceipt binds the exact lease. Goal admission never grants execution authority.

Human-effect materiality is action+target/effect-scope bound and content-addressed. Unknown or unvalidated materiality is
non-PASS. A proposer cannot self-label a material effect as harmless.

GOVERNED TRANSITION FABRIC

Existing Engine.Transition / Garden Transition Fabric remains the semantic owner. Standard high-assurance progression:
  SHADOW -> PARALLEL -> BOUNDED_ACTIVE -> EXPANDED_ACTIVE -> STABLE_OPERATION.

Stage omission requires an explicit stage-specific reason and separately resolved omission assurance; remaining stages
preserve standard order. Entry/exit criteria are non-vacuous and belong to a validated criteria profile.

TransitionAssuranceReceipt is bound to the exact transition_id, effect_scope, current/target stage, DesignEpoch,
authority/hard-gate/criteria/recovery snapshots, AuthorityDelta digests, evidence and verifier independence.

Stage status creates no authority. Any authority migration is carried only by an explicit typed AuthorityDelta with
delegator/recipient, action/resource/subject scope, jurisdiction/context, invalidators, revocation, appeal, evidence and
independence/conflict bindings. Approval is content-addressed over the full delta.

PARALLEL divergence is evidence to investigate; neither incumbent nor Garden output is truth by status. Material
unresolved divergence blocks expansion. Capture/conflict risk changes assurance.

For reversible committed effects, confirmed material failure can trigger fresh recovery admission and rollback only to
the recorded last qualified stage. For irreversible effects, recovery uses authorized compensation/recovery rather than
fictional rollback. Recovery never creates authority.

Each public advance/recovery decision emits a content-addressed TransitionReceipt recording the evaluated proposal,
assurance binding, decision and reasons. A receipt records a decision; it does not self-validate the decision.

AI-LED UPGRADE CLOSURE

Routine specification closure is AI-owned work within existing authority:
  RECONSTRUCT -> MAP -> SEARCH -> CLASSIFY -> GATHER -> GENERATE including DO_NOTHING -> ATTACK -> VERIFY -> COMPARE ->
  INTEGRATE -> PROPAGATE -> RE-AUDIT -> REPEAT within declared bounds.

FindingClass:
  ROUTINE
  MATERIAL
  HARD_GATE
  PROTECTED

Finding dispositions:
  FIXED
  REJECTED_WITH_EVIDENCE
  DEFERRED_WITH_OWNER_CONDITION
  ESCALATED
  OPEN

HARD_GATE and PROTECTED findings cannot be deferred/escalated into positive closure for the affected scope. A PROTECTED
finding activates the protected-change authorization path even if the proposer labels the overall change routine.

Upgrade closure is bound to:
- exact candidate SHA-256;
- explicit audited-scope SHA-256;
- search coverage of that scope;
- evidence-backed finding dispositions;
- method authority;
- dependency propagation;
- tests/checks;
- retention/no-loss result;
- required verification independence/review;
- protected authorization where applicable;
- final re-audit after the last material change.

Closure evidence from an older candidate cannot be replayed after bytes change. Classification and protected-surface
scans are candidate-bound and independently validated where required.

Each upgrade cycle has bounded work/iteration/resource/review limits and a residual-debt record. Repeated low-value
duplicate findings do not force infinite recursion; new material findings inside the audited scope reopen closure.
