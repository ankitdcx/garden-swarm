# GCSC Epoch-1 bounded conclusion

Status: NONCANONICAL / BOUNDED RESULT

## What was actually demonstrated

The current independent GCSC kernel generated 11 L2 candidate obligations before consulting the v15.9 invariant catalogue.

Post-discovery comparison found:
- 8 clearly rediscovered existing semantics;
- 2 rediscovered existing semantics or a direct refinement of them;
- 1 case (ownership-vs-control distinction) already has broad semantic support but no single exact invariant was established in the bounded search;
- 0 confirmed novel Garden gaps from this small L2 seed set.

This is useful validation of the method, not evidence that Garden has no gaps.

## Strong rediscovery examples

1. Delegation cannot amplify authority -> AGT-002 / P15 / parent-authority-envelope rules.
2. Collective membership cannot union authority -> S15.8-7 / organizational-alignment theory.
3. Chained epistemic support cannot amplify certainty automatically -> P2 + composition/well-foundedness rules.
4. Causal chaining requires causal model/SCM and assumptions -> P12 + causal reasoning contract.
5. Dependency changes require revalidation -> P7a/P7b + OCF dependency-aware revalidation.
6. Scope/context/assumption compatibility in composition -> P3/P6/MATH-003.

## Why a full 1,817-invariant rediscovery percentage is not yet defensible

A rediscovery denominator is meaningful only if the independent generator is capable of generating the semantic domain of each existing invariant. The current kernel intentionally covers primitive relation semantics plus a small set of L2 compositions. It does not yet independently generate all physical, privacy, security, lifecycle, legal, finance, compiler, hardware, theory, domain, or deployment semantics represented by the 1,817 v15.9 invariants.

Counting those ungenerated domains as "missed" would measure generator scope, not Garden coverage.

## Correct next expansion

The generator must be expanded by semantic coverage classes, not by reading invariant text:
- authority/consent/rights;
- epistemics/evidence/provenance;
- dependency/version/lifecycle;
- composition/concurrency;
- human effects/privacy;
- safety/physical effects/recovery;
- resources/termination;
- security/adversarial;
- law/jurisdiction;
- evolution/self-modification;
- collective/multi-agent;
- world/context/temporal;
- representation/compile/runtime;
- domain/theory applicability.

Each class should generate obligations from the independent GCSC materiality model, then only afterward compare to the catalogue.

## Current conclusion

GCSC has passed its first blind-rediscovery sanity test: it can reconstruct known Garden semantics without being given the invariant catalogue. The bounded run has not yet discovered a confirmed new invariant missing from v15.9. The ownership/control distinction remains the first candidate for dedicated strengthening, but current Garden semantics already broadly prohibit authority creation from ownership/intent/capability, so it is not classified as a confirmed gap.
