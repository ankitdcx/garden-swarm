# GSL Combinatorial Semantic Coverage (GCSC) v0.1

Date: 2026-09-21
Status: DESIGN / ANALYSIS INSTRUMENT / NO AUTHORITY EFFECT

## Purpose

Measure how well Garden schemas, invariants and tests govern the semantic situation-space generated by the abstract GSL basis, without enumerating every concrete runtime state.

## Fixed basis

Pillars: 6
Core Objects: 10
Core Relations: 24
Design Forms: 7
Facets: 10
Macros: 21
Maximum canonical nesting depth: 64

A naive one-choice cross-dimensional cell has:
6 * 10 * 24 * 10 * 7 * 10 * 21 = 21,168,000 raw cells.

This number is a search envelope, not the count of meaningful Garden situations.

## Why exhaustive concrete enumeration is invalid

Garden structures are typed recursive graphs. Multiple objects, relations, forms and facets can coexist; values and instances are unbounded; nesting reaches depth 64. Therefore concrete-state enumeration is neither finite enough nor semantically useful.

Coverage is measured over equivalence classes and generated motifs.

## Validity pipeline

A candidate combination is REALISTIC only if it survives all applicable gates:

1. SYNTACTIC — fields, cardinalities, canonical serialization and nesting are valid.
2. FORM-BINDING — selected Design Form is compatible with its declared GSL object/relation binding.
3. MACRO-BINDING — selected Macro actually permits the selected Form set; identical Form sets never infer a Macro.
4. TYPE — source/relation/target types are admitted by relation/schema typing. Absence of a type rule is UNKNOWN, not valid.
5. FACET-APPLICABILITY — facet is materially relevant to the candidate; irrelevant facet multiplication does not create a new semantic class.
6. PILLAR-APPLICABILITY — pillar changes interpretation/obligation materially; otherwise pillar variants collapse to one equivalence class.
7. CONTEXT — required context/scope/time/agency/authority information is present or candidate is CONTEXT_REQUIRED.
8. CONSTRAINT — hard rights, authority, safety, privacy, law, epistemic and resource constraints do not make the candidate prohibited.
9. STATUS — CURRENT/CANDIDATE/DEFERRED/UNKNOWN/STALE/BLOCKED etc. remain explicit.
10. COMPOSITION — for multi-edge motifs, individually valid edges must also be valid jointly; common-cause/emergence/conflict is checked.
11. EFFECT — materially different external/human effects create distinct semantic classes.
12. OBSERVATIONAL_EQUIVALENCE — candidates producing the same typed obligations, permissions, statuses, effects and invalidators collapse into one class.

Outputs:
VALID_COVERED
VALID_PARTIAL
VALID_UNCOVERED
CONTEXT_REQUIRED
INVALID_TYPE
PROHIBITED
AMBIGUOUS
CONFLICT
UNKNOWN

Only VALID_* cells count in the denominator for ordinary coverage. CONTEXT_REQUIRED/AMBIGUOUS/UNKNOWN are reported separately and never counted as covered.

## Coverage hierarchy

L0: 2,400 Object-Relation-Object primitive triples.
L1: 21,168,000 raw Pillar × source × relation × target × Form × Facet × Macro cells, reduced by the validity pipeline.
L2: connected two-edge motifs sharing at least one node.
L3: connected three-edge motifs.
L4: constitutional motifs containing consequential ACTION/AGENCY plus applicable RULE/VALUE/CONTEXT/CLAIM structure.
L5: adversarial/property-generated recursive graphs up to depth 64.

Do not attempt all L2+ Cartesian products. Generate connected, type-admissible motifs and quotient by typed graph isomorphism plus observational equivalence.

## Realism score for prioritization, not validity

After validity classification, prioritize testing with:

R = M * (1 + H + A + E + U + C + N)

where:
M = materiality gate (0 if no meaningful semantic/effect difference; else 1)
H = human-effect relevance
A = authority/rights relevance
E = epistemic/evidence relevance
U = uncertainty/unknown sensitivity
C = compositional/emergent interaction
N = novelty / weak historical test coverage

Each factor is ordinal 0..3. R does not authorize or prohibit anything. It only orders coverage work.

## Schema/invariant coverage rule

A valid class is COVERED only when the current Garden package provides:
- an applicable owner/schema or explicit generic owner rule;
- all applicable hard invariants;
- explicit non-PASS/UNKNOWN behavior;
- applicable authority/human-effect boundary when consequential;
- invalidation/revalidation behavior where dependencies can change;
- at least one deterministic or property-based test oracle for material hard constraints.

A name match or historical reference is not coverage.

PARTIAL means some applicable obligations are bound but at least one material obligation has no current rule/test.

UNCOVERED means the class is valid but no sufficient current governing contract can be derived.

## Coverage metrics

PrimitiveCoverage = VALID_COVERED_L0 / VALID_L0
CrossDimCoverage = VALID_COVERED_L1 / VALID_L1
HardConstraintCoverage = covered applicable hard obligations / applicable hard obligations
TestCoverage = valid material classes with executable/property oracle / valid material classes
CompositionCoverage_k = covered generated connected motifs at k edges / valid generated connected motifs at k edges
UnknownResolutionRate = classes explicitly producing UNKNOWN/CONTEXT_REQUIRED rather than accidental PASS / classes requiring such treatment

Report Wilson/bootstrap uncertainty for sampled L2+ coverage; never present sample percentage as exhaustive proof.

## Filling strategy

Phase A: deterministically classify all 2,400 L0 triples.
Phase B: deterministically generate all 21,168,000 L1 raw cells, then reduce using Form/Macro/type/applicability/equivalence rules. Store only canonical representatives and counts of collapsed cells.
Phase C: enumerate all admissible connected L2 motifs where feasible; otherwise stratify by relation/facet/macro/hard-boundary class.
Phase D: property-based L3/L4 generation weighted by realism score and boundary risk.
Phase E: recursive adversarial generation to depth 64 using coverage-guided novelty search.

## Anti-gaming rules

- Invalidating a difficult combination cannot improve coverage unless the invalidity rule is itself explicit and justified.
- Generic catch-all schemas count only when they derive the same obligations as specialized cases.
- UNKNOWN is preferable to invented coverage.
- Two rules that conflict do not count as double coverage; they produce CONFLICT.
- Review-model agreement is not coverage.
- Historical test frequency may prioritize generation but cannot define semantic validity.
- Coverage percentages never create authority or certification.

3. L1 generator/reducer;
4. schema/invariant/test binding index;
5. coverage report with uncovered representatives;
