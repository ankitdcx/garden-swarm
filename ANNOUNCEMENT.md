# Garden Public Launch Announcement

**Garden v15.5 / GSL v45.1 is open for worldwide inspection, criticism, independent reproduction, and Garden-compatible implementation.**

Garden is a proposed human-facing architecture for increasingly capable AI/AGI systems. Its central rule is:

> **Capability != Authority != Sovereignty != Moral Permission**

The project attempts to combine human sovereignty, rights, privacy, consent, typed authority, evidence/provenance, explicit uncertainty, comparison/reasoning, proof/assurance, auditability, reversibility, community legitimacy, and continuous self-correction while allowing machine cognition to become substantially more capable than humans.

The originator has authorized public disclosure of the complete Garden design. Public disclosure does not itself grant a patent licence to protected inventions outside Garden; see the repository rights notice.

The invitation is simple:

- read it;
- attack it;
- compare it against stronger alternatives;
- find counterexamples;
- reproduce its tests;
- implement safe subsets;
- benchmark it against current systems;
- propose better designs when evidence supports them.

Do not treat Garden as proven merely because it is specified. `specified != proved != implemented != empirically validated != certified`.
