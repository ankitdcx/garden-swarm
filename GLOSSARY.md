# Garden Public Glossary

This is a reader aid, not an independent normative source. If wording here conflicts with the canonical five-file v15.5 source, the canonical source controls.

- **AAP** — Activation and Assurance Policy. Chooses the smallest sufficient Garden mechanisms and assurance depth while preserving mandatory hard requirements.
- **A2A** — Agent-to-Agent protocol family used for machine-to-machine agent discovery and interaction.
- **ActionGate** — Garden's deterministic external admission boundary for consequential tool/device/external-system operations.
- **AGI** — Artificial General Intelligence. Garden does not assume intelligence itself creates authority.
- **Capability** — What an actor/system can technically do. Capability is distinct from permission, authority, sovereignty, evidence, or moral permission.
- **Capability token / delegation receipt** — Scoped, verifiable evidence that a principal delegated specific capability under declared limits; it does not create rights or factual truth.
- **CLIC** — Cross-Layer Integrity/Causality/continuity hardening family used in current Garden source lineage.
- **DesignEpoch** — Versioned design/semantic state used to bind artifacts, assumptions, dependencies, checks, and invalidation.
- **GAIA Diamond** — Reference assurance/authorization architecture above/across devices; emits bounded capability eligibility tokens. Specification status does not imply deployment certification.
- **GAIA Titanium** — Reference hard-real-time local physical-control/safety architecture with local veto semantics. Specification status does not imply certified implementation.
- **GCL** — Generalized Causal Leverage analytical profile.
- **GSL** — Garden Semantic Language / semantic foundation. GSL v45.1 is the current version bound to Garden v15.5.
- **GSL-KR** — Garden knowledge/claim/evidence/provenance representation and storage discipline.
- **HITL** — Human in the Loop. In this repository, the originator/HITL may clarify original design intent; that role creates no general authority over unrelated humans.
- **HSA / Human Sovereignty** — Garden's human-sovereignty boundary: AI capability does not silently become authority over humans; rights, consent, privacy, law, safety, and legitimate governance remain separately checked.
- **K0P** — Garden's non-sheddable physical safety/veto root for applicable controlled physical actuation.
- **MCP** — Model Context Protocol. Used for exposing tools/resources to compatible AI clients; a Garden MCP registry listing should wait for a real conformant endpoint.
- **OCF** — Operational Closure Framework. Material requirements must end in an executable/implementable contract, derivation/design/discovery path, or visible blocked frontier rather than persuasive prose alone.
- **PCCD** — Proof-carrying change/delta style dependency-local reverification pattern used in Garden assurance/change handling.
- **Privilege rings (R0-R4)** — R0 protected roots; R1 qualified system services; R2 bounded admitted agents; R3 generated/experimental code; R4 untrusted external content/data.
- **TRAIN** — Garden reference transport/system architecture family.
- **UNKNOWN / STALE / BLOCKED / INCONCLUSIVE** — Explicit non-success states. Garden avoids collapsing these into ordinary TRUE/FALSE or implicit success where the operation is not total and deterministic.

Core shorthand:

> **Capability != Authority != Sovereignty != Moral Permission**
